# V1.4 开发与接入说明

产品范围以《V1.4确认需求.md》及 PRD V1.4 第17章为准。原 V1.3 文件保留作版本基线。

## 悬赏规则实现

所有悬赏退款入口共用保护检查：帖子加锁、异议窗口、未结或成立争议、有效线索核验、找回状态。确认找回与争议提交同样锁帖子。默认到期后72小时内不退；有效线索无核验结论不退。管理员可逐条处理争议、选择有效线索确认找回，之后复用7天默认评分和既有人工转付。新增到期异议通知给发布者及线索提供者。

只更新数据库状态不能证明线下事实，运营仍须核对凭证；不保证绝对防止骗退或导流。现有退款通道对异步微信退款的最终成功状态仍需真实回调联调核验，不能仅因调用未抛异常就认定银行侧已到账。

## AI 网关配置和协议

Spring属性通过环境变量配置：`RONGPET_AI_GATEWAY_URL`（对应`rongpet.ai.gateway-url`）、`RONGPET_AI_GATEWAY_KEY`。地址由部署者设置为可信图像网关，不从用户输入获取。未配置网关时API明确拒绝创建，不计次数、不收费。当前仓库提供任务、额度、计费和网关客户端，**没有绑定具体商业图像供应商**，也未验证真实生成效果。

网关请求为POST JSON，Authorization为Bearer密钥：

```json
{"taskId":"任务ID","sourceUrl":"本人宠物真实头像地址","style":"STORYBOOK","preserveFeatures":true}
```

style可为STORYBOOK、SOFT3D、WATERCOLOR。网关须以taskId幂等，保留特征，完成供应商调用、内容安全检测和对象存储归档，并在180秒内返回：

```json
{"imageUrl":"https://可信存储的结果地址","safetyPassed":true}
```

Worker按任务状态条件领取，避免多个实例重复领取同一任务；超过10分钟的进行中任务判失败，成功才占免费次数。默认每宠免费3次，超过后使用配置价格快照。价格默认0表示未定价，不能发起付费。付费使用既有支付通道，成功后入队；失败进入原路退款和异常重试。私有图片源若为过期签名URL，需要图像网关／存储接入时解决续签，不能将过期地址视为永久资产。

## 原型交付

`prototype/index.html`是独立可打开的HTML，V1.4扩展已经内联，不依赖额外JS文件。`prototype/v14.js`保留作扩展源，修改后执行`python tools/build_prototype.py`重新内联。宠物示例照片需要联网，用户上传照片只保存在当前浏览器。原型不自动接入Spring Boot，不产生真实支付和AI调用。

原型覆盖新导航、场景、互动、当前宠物联动、搜索筛选、发布确认和草稿、费用说明、审核模拟、站内会话、建议反馈、请求与认证、订单和争议规则。模拟审核按钮仅在折叠的原型工具中，正式用户端不提供。反馈详情已去掉用户自行模拟管理员回复入口。

## 仍需接入和验收的事项

- 配置并验证真实MySQL/Redis，执行V7，验证数据库事务、并发与SQL兼容性；本轮未在真实数据库上执行迁移。
- 选择并部署上述图像网关／供应商，验证真实照片生成、对象存储、内容安全及失败退款。AI生成收费上线前验证对应微信支付能力；价格未配置前不开放收费。
- 小程序真实微信登录、手机号授权、支付回调、异步退款成功、订阅消息、定位等能力需凭证和真机联调。
- PRD既有“图片相似度匹配”和“含真实小程序码的服务端分享海报”尚未在本轮实现；现有后端只有条件匹配，原型海报只作布局预览。
- 原型中的所有业务仍为本地模拟，未逐一联调所有正式接口；运营后台本轮新增的是API，不包含完整PC网页。
- 图片授权访问、私有资源续签、会话举报／封禁、后台争议补证及处理时效等上线验收仍需继续完善，当前文字拦截不能防止全部联系方式变体。
- PRD V1.4已生成并可结构读取；本机缺少LibreOffice，未完成Word分页渲染检查。

上述事项应作为上线前的执行清单，不能因原型可点击或单元测试通过而勾选完成。
